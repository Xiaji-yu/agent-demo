### M1（线1，已复现）push 空内容两条出口不归还预占，空耗目标当日全部打扰预算——M13 修复的回归

- **位置**：`agentcore/scheduler/push.py:527`（transient 空内容 `return "capped"`）与 `:531`（配置空 `return "disabled"`）。
- **证据**【已复现：读码 + 子代理真实现仿真】`_cap_reached`（L508）在闸门处预占（`notify_budget.reserve` 锁内立即 `bucket[kind]+1` 并 `_save` 落盘，notify_budget.py:258-266 主代理核读坐实）；uncertain/failed/sent 三出口均正确 rollback/commit（L542/L548/L553），唯独空内容两出口直接 return：
  ```python
  text, transient = await self._content(params)
  if not text:
      if transient:
          ...
          await self._reschedule(row, now)
  ```

- **建议**：两出口补 `if reserve is not None: reserve.rollback()`；`test_notify_budget.py` 加「空内容出口必须归还」用例（变异：去掉任一出口 rollback → 红）。

## 2. 被证伪的发现
