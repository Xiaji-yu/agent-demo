## 1. H 级修复

### H1｜Anthropic 多模态 content 被 `str()` 化

- **修法**：`agentcore/llm/protocols.py` 新增 `_image_block` / `_content_blocks`。
  - `data:image/<subtype>;base64,<payload>` → Anthropic
    `{"type":"image","source":{"type":"base64","media_type":...,"data":...}}`；
  - `http(s)://` → `{"type":"image","source":{"type":"url","url":...}}`；
  - 不支持的形式丢弃并 WARNING；
  - `role=tool` 的数组 content 同样映射；assistant 只取 text（图片不应出现在 assistant 消息）。
- **回归**：`tests/test_llm_protocols.py::TestAnthropicMultimodal`
  （data URI + https 两种 image block；base64 不出现在 text；非法 scheme 丢弃）。
- **变异复核**：把 user 内容改回 `str(content)` → 用例必红（已实测）。

### H2｜provider 改端点继承旧 key + test 无确认/审计

    也未 `clear_key` → **409 `provider_key_required_for_endpoint_change`**；

  - `provider_probe_detail` 只回状态码，不再回显上游响应体（M6）；
  - `/model` 错误回执/日志用 `_safe_spec` 去掉 `|key` 并截断（L13）。
- **回归**：
  - `test_endpoint_change_requires_new_key` / `..._with_new_key_allowed` /
    `test_protocol_change_requires_new_key`；
  - `test_test_action_is_audited`；
